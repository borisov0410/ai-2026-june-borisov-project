# AI Test Generator (Ollama + Pytest)

Проект демонстрирует использование локальной LLM (через Ollama) для автоматической генерации тестовой документации и автотестов на основе текстового описания функционала.

## Критерии успеха
- [x] Скрипт принимает описание функционала.
- [x] Генерируются тест-кейсы, тестовые данные и автотесты.
- [x] Каждый тип артефактов сохранён в отдельный файл.
- [x] Автотесты запускаются через pytest.

## Требования
1. Python 3.8+
2. Установленный и запущенный [Ollama](https://ollama.com/)
3. Загруженная модель (`qwen2.5-coder:7b`)
